# S5Tech Code Challenge

This repository contains solutions for the S5Tech backend code challenge.  
The implementation is organized into separate modules for each problem to ensure clarity and ease of review.

---

## Structure

```
/problem4-sum-to-n
/problem5-crude-server
/problem6-architecture
```

---

## Problem 4: Sum to N

Implementation of three different approaches to compute the sum from 1 to n.

### Approaches

1. Iterative (Loop)  
2. Mathematical Formula  
3. Recursive  

---

## Problem 5: Crude Server

A backend CRUD service built with Express, TypeScript, and Prisma.

### Features

- Create, read, update, delete resources
- SQLite database with Prisma ORM
- Centralized error handling
- Standardized API response format
- Swagger API documentation

---

## Problem 6: Architecture

Design specification for a real-time scoreboard system.

### Includes

- System architecture design
- Execution flow
- API specification
- Security and anti-cheat strategy
- Scalability considerations
